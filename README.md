# FRED Homework

Course: ADEC 7900 – Software Tools

This homework uses R and FRED data to analyze U.S. economic trends over the past 20 years.

The analysis includes the Federal Funds Rate, 10-Year Treasury Yield, inflation, unemployment, and U.S. recessions. The final plot compares the Federal Funds Rate and 10-Year Treasury Yield to discuss the mortgage market.

Files
- FRED HW update.Rmd – R Markdown code and analysis.
- FRED HW update.pdf – Completed homework with charts and written analysis.
- FRED_data.RData – Saved FRED datasets used for the analysis.

Data Source: Federal Reserve Economic Data (FRED)
